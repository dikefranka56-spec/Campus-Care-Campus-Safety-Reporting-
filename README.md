# CampusCare — Campus Safety Reporting UI

A responsive frontend prototype for a campus safety reporting experience.

## Features
- Mobile-first responsive layout
- Report form with client-side validation and local confirmation
- Safety guidance and privacy notice
- Accessible labels and clear demo disclaimer

## Run
Open `index.html` in any modern browser. No installation or build process is required.

## Important
This is a frontend-only portfolio demonstration. Reports are not sent, stored, or monitored. Do not enter real personal or incident data. Do not describe this as a live security reporting service.
